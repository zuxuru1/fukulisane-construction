# Fukulisane Construction Platform

Standalone construction business management platform.

## Quick Start

```bash
npm install
cp .env.example .env
npx prisma db push
npm run dev
```

## Deploy to Vercel

1. Push to GitHub
2. Import on vercel.com
3. Set DATABASE_URL and NEXTAUTH_SECRET
4. Deploy

## Tech Stack

- Next.js 14 + React 18 + TypeScript
- Tailwind CSS + shadcn/ui
- Prisma 6 + PostgreSQL
- Recharts + Lucide React
